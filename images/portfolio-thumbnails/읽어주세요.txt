포트폴리오 썸네일 캡처

- PNG 65장. 원본 프로젝트 번호를 유지했습니다.
- 브라우저 viewport는 모두 정확히 1440 x 900, 페이지 최상단입니다.
- 팝업은 닫았고, 사이트 고유의 상담 버튼·메뉴·배너는 유지했습니다.
- 스크롤바가 들어가지 않도록 해당 영역을 잘라냈습니다. 따라서 저장 파일의 크기는 모두 1440 x 900으로 동일하지 않습니다.
  일반 파일: 1425 x 900 또는 1440 x 900
  73 누리서비스와 76 리버무역: 가로·세로 스크롤바 영역 제외로 1425 x 885
  35 신기전선: 영역 캡처에서 흰 화면이 반환되어 기본 캡처로 대체하고 스크롤바를 잘랐습니다. 도구의 축소 출력으로 1410 x 891입니다.
- 이미지를 늘리거나 빈 부분을 합성하지 않았습니다.
- 브라우저가 제공한 JPEG 캡처를 실제 PNG 형식으로 변환했습니다. 원래 캡처의 압축 품질은 유지됩니다.
- 사이트별 최종 파일 크기와 URL은 캡처목록.txt에 있습니다.
- index.html을 열면 썸네일 전체를 둘러보고 원본 PNG를 클릭해 볼 수 있습니다.
- 05 양전자시스템, 06 에프엔에스테크, 17 케이에스섬유는 사용자 목록상 서브 작업 프로젝트입니다. 이번 요청에 따라 메인 화면을 캡처했습니다.
- 사이트 내용과 자동 슬라이드 장면은 캡처 당시 화면 기준입니다.
